Arquitetura Implementada — BI de Internações Hospitalares HUOL/UFRN

Pipeline ETL em camadas · Data Lake S3-compatível (MinIO) · Data Warehouse PostgreSQL (esquema estrela) · NLP · Dashboard Streamlit
FONTES OFICIAIS

Portal gov.br — HUOL/UFRN

  • 8 CSVs trimestrais (2024–2025)
  • PDFs originais não incluídos no repositório
  • Base “06. Internações Hospitalares”
  • Referência IBGE (5.571 municípios)
  • Instagram Graph API (módulo NLP)
BRONZE — dados brutos

Ingestão fiel (bronze_ingest.py)

  • Cópias originais sem alteração
  • hash SHA-256 + manifestos JSON
  • origem, período e data de ingestão
  • ingestão idempotente
PRATA — dados tratados

Padronização (silver_transform.py)

  • datas/idades tipadas; sexo e especialidade normalizados
  • município validado no IBGE + classificação geográfica
  • faixas etárias; flags de qualidade
  • Parquet particionado por ano
OURO — dados analíticos

Curadoria (gold_curate.py)

  • 11 conjuntos analíticos Parquet
  • por especialidade, município, sexo, faixa
  • mês/trimestre/ano; 2024×2025
  • indicadores gerais + qualidade
DATA WAREHOUSE — PostgreSQL

Esquema estrela (schema.sql + load_warehouse.py)

  • Fato_Internacao: 16.046 eventos (qtd = 1/evento, hash rastreável)
  • Dim_Tempo · Dim_Especialidade · Dim_Municipio · Dim_Demografia
  • chaves substitutas, membros desconhecidos (−1)
  • carga idempotente; vista vw_internacoes
DASHBOARD — Streamlit + Plotly

7 telas analíticas (app.py)

  • Visão Executiva · Especialidades · Demografia
  • Geografia · Sazonalidade · Sentimentos · Insights
  • filtros globais SQL (ano, trimestre, mês, especialidade, município, sexo, faixa)
  • formatação brasileira; estados vazios explícitos
NLP — comentários do Instagram

instagram_client · clean_text · sentiment · topics

  • Instagram Graph API oficial (token/permissões)
  • limpeza textual + lematização pt-BR
  • sentimentos: cardiffnlp/twitter-xlm-roberta-base
  • temas: TF-IDF (1–2 gramas) por sentimento
  • sem dados autorizados: estado pendente (sem simulação)
INFRAESTRUTURA

docker-compose.yml

  • MinIO :9000 (API S3) + Console :9001
  • PostgreSQL 16 :5432 (huol_dw)
  • volumes persistentes ./volumes/
QUALIDADE

tests/ (pytest)

  • leitura, conversões, normalizações
  • integridade referencial fato × dimensões
  • consistência DW × Ouro; idempotência
GOVERNANÇA

LGPD e rastreabilidade

  • sem identificador de paciente (base anonimizada)
  • texto original preservado no NLP
  • manifestos + hash_linha + logs
Fluxo: arquivos oficiais → Bronze (cópia fiel) → Prata (padronização/validação IBGE, Parquet) → Ouro (agregados analíticos) → Data Warehouse (estrela) → Dashboard. Camada NLP alimenta a Ouro quando comentários autorizados forem carregados. Armazenamento S3-compatível (MinIO em produção; SeaweedFS validado em desenvolvimento, mesma API S3).
